# 02-requirements: Exact rules and quality targets

| File | What it contains |
|---|---|
| [specs.md](specs.md) | Functional requirements (FR: what the system must do), non-functional requirements (NFR: how well), and every numeric limit |
| [performance-requirements.md](performance-requirements.md) | Latency budgets, throughput targets, memory limits and how they are measured |

Requirements are **testable statements**. Stories say *what users want*; specs say *exactly what the system must do* to deliver it.
