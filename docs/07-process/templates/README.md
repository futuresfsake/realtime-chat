# Templates

Copy a template, rename it, fill it in.

| Template | Use when |
|---|---|
| [feature-spec-template.md](feature-spec-template.md) | Planning a new feature |
| [user-story-template.md](user-story-template.md) | Adding a story to `user-stories.md` |
| [adr-template.md](adr-template.md) | Recording an architecture decision |
| [bug-report-template.md](bug-report-template.md) | Writing up a bug (also available as a GitHub issue form) |

GitHub uses the templates in `/.github/` automatically for PRs and issues.
