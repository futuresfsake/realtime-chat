# Templates

Copy a template, rename it, fill it in.

| Template | Use when |
|---|---|
| [feature-spec-template.md](feature-spec-template.md) | Planning a new feature (F-##) |
| [user-story-template.md](user-story-template.md) | Adding a story (US-##) |
| [adr-template.md](adr-template.md) | Recording an architecture decision |
| [bug-report-template.md](bug-report-template.md) | Writing up a bug (also available as a GitHub issue form) |

GitHub uses `/.github/pull_request_template.md` and `/.github/ISSUE_TEMPLATE/*` automatically.
