# 01-product: What we build

| File | What it contains |
|---|---|
| [milestones.md](milestones.md) | The plan: M0–M8, each with goal, stories, features, exit criteria (milestone DoD), effort and risks |
| [user-stories.md](user-stories.md) | Every user story (US-##) with acceptance criteria and the story-level Definition of Done |
| [features.md](features.md) | Every feature (F-##), its status, milestone and source stories |
| [slash-commands.md](slash-commands.md) | Exact behavior of every `/command` |

**How they relate:** a **milestone** groups **stories** (user value). Each story is delivered by one or more **features** (the things we build).
